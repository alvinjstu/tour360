# 版本更新记录

## v0.1.0 (2025-03-31)

### 新功能
- 首次发布基础版本
- 支持Windows和Mac系统
- 支持上传多个全景场景
- 支持场景热点设置与跳转
- 添加平面示意图功能
- 实现消息滚动走马灯
- 支持离线使用，无需网络连接

### 修复
- 初始版本，暂无修复项

### 已知问题
- 在某些低配置设备上可能存在性能问题
- 部分浏览器可能存在兼容性问题

## 未来计划

我们计划在未来版本中添加以下功能：

- 支持VR设备直接查看
- 添加更多交互元素
- 优化性能，提升加载速度
- 增加更多自定义选项
- 支持更多全景图像格式
